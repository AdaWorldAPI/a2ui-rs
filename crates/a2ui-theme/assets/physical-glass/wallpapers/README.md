# Physikalisches Glas: wallpapers

Backgrounds for the `physical-glass` material, chosen per browser in the
material's background selector.

| file | label | look |
|---|---|---|
| `aurora.webp` | Polarlicht | dark blue to teal with a rose corner, two light curves |
| `night.webp` | Nacht | dark blue-grey, cyan, red and blue light curves, a fine grid at the bottom |
| `morning.webp` | Morgenlicht | pale blue, light from the upper left, two curves |
| `rose.webp` | Rosé | pale white with rose and blue corners, crossing curves |
| `lagoon.webp` | Lagune | pale blue to turquoise, crossing curves |
| `mint.webp` | Minze | pale blue with a mint top and a rose corner, crossing curves |
| `pearl.webp` | Perlmutt | pale blue with iridescent glass ribbons |
| `crystal.webp` | Kristall | light blue-grey, faceted glass ribbons with red accents |
| `deepsea.webp` | Tiefsee | dark blue, cyan, red and blue light curves |
| `neon.webp` | Neon | near black, red and blue neon lines, glass panes on the right |

Provenance: original images generated with an image model and supplied by the
project owner on 2026-11-26 for use in this repository (the second five later
the same day). They imitate no
vendor wallpaper. 1672×941 WebP, 20 to 61 KB each; scaled to cover the page.

Refraction shows where a line crosses a surface edge. These images are soft
gradients with a few light curves, so the glass bends only those curves; the
contour rings and brushed metal backgrounds show it on every edge.
