# Physikalisches Glas: wallpapers

Four backgrounds for the `physical-glass` material, chosen per browser in the
material's background selector.

| file | label | look |
|---|---|---|
| `aurora.webp` | Polarlicht | dark blue to teal with a rose corner, two light curves |
| `morning.webp` | Morgenlicht | pale blue, light from the upper left, two curves |
| `rose.webp` | Rosé | pale white with rose and blue corners, crossing curves |
| `lagoon.webp` | Lagune | pale blue to turquoise, crossing curves |

Provenance: original images generated with an image model and supplied by the
project owner on 2026-11-26 for use in this repository. They imitate no
vendor wallpaper. 1672×941 WebP, about 20 KB each; scaled to cover the page.

Refraction shows where a line crosses a surface edge. These images are soft
gradients with a few light curves, so the glass bends only those curves; the
contour rings and brushed metal backgrounds show it on every edge.
