# Morpheus Desktop launcher pictograms

256 × 256 RGBA PNG. Each picture is one glass squircle with its pictogram, cut out
of the project owner's launcher design (2026-11-26) along the squircle outline;
outside the outline the picture is transparent. The launcher shows them at 112 px,
the rail at 32 px.

| file | app |
|---|---|
| `a2ui.png` | A2UI Oberfläche |
| `service-hub.png` | Service Hub |
| `material-lab.png` | Materiallabor |
| `workspace.png` | Arbeitsplatz (the desktop's own mark in the top bar) |
| `aduc.png` | Active Directory (ADUC view of the portal). Drawn for this repository on 2026-11-26 in the style of the launcher design; not cut from it |
| `m365/outlook.png` | Outlook |
| `m365/teams.png` | Teams |
| `m365/word.png` | Word |
| `m365/excel.png` | Excel |
| `m365/onedrive.png` | OneDrive |
| `m365/sharepoint.png` | SharePoint |

The `m365/` pictures are unofficial interpretations of Microsoft product icons,
kept in their own folder so they can be replaced (by letter tiles or by
Microsoft's official icons under its brand guidelines) without touching the
others. Their use is the owner's decision.
