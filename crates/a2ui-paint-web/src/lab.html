Glass is judged against something behind it. This page puts one element over backgrounds whose structure is known: a checkerboard shows displacement, lines show distortion, the black and white halves show transmission, the coloured bands show any dispersion, and this text shows how readable a page stays under the material. Every map on the element is computed by the a2ui-paint optics engine on the server; the page only asks for it. Drag the element to see the lensing move over the background. The rear light is a separate field behind the element. It fades to transparent inside its own box and has no mask, so it can never draw an outline.
